# Q: Give me a run down of this project

## Answer

MMR Homefinder supports Mumbai-region new-home discovery through buyer, builder and reviewer workflows. Three Django entrypoints share platform_api, PostgreSQL, media and React/Vite sources; durable workers process evidence, layouts and signed-in recommendations. Independent review gates publication. WORKFLOWS.md is the canonical operating guide; MAINTAINERS.md records architecture and a failing historical backend baseline. Cloud plans do not establish a live deployment.
